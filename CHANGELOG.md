# Changelog

All notable user-facing changes to TrashDash are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Responsive desktop game with original CSS and inline SVG artwork.
- Smooth mouse, touch, pen, and keyboard document dragging.
- Ten shuffled trash-bin refusal behaviors and seven-attempt progression.
- Final acceptance celebration with the message “Trash accepted reluctantly.”
- Generated Web Audio sound effects, sound toggle, and reset control.
- Reduced-motion behavior, focus indicators, live status messages, and keyboard guidance.
- Dependency-free project verification and production documentation.
