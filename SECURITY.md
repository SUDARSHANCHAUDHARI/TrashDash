# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's
private **Security → Report a vulnerability** form on GitHub and include:

- the affected file or behavior;
- steps to reproduce the issue;
- the potential impact; and
- any suggested remediation, if known.

Do not include access tokens, credentials, private keys, or personal data in a report.

TrashDash has no backend, account system, persistent user storage, or intentional network
requests. Reports involving unsafe markup handling, unexpected outbound requests, supply
chain changes, or hosting configuration are still in scope.
